# YDArcadeEngine

C++20 / raylib 5.5 oyun engine'i. Oyunlar bu repoyu kökünde `Engine/` submodule'ü olarak alır.

- Belgeler: [Docs/README.md](Docs/README.md)
- Yeni proje: proje klasörüne `Engine/` olarak koyun, içinde `python EngineSetup.py`
  ([Docs/ProjectSetup.md](Docs/ProjectSetup.md))
- Engine testleri: `python Tools/build_cli.py --test`
